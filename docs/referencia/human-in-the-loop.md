## 🎯 Por que importa

Só cerca de **1/3** dos critérios é verificável por automação pura. O restante exige interpretação — e é aí que IA + humano se complementam.

## 🙋 Quando o humano entra

- 🔐 **Segurança:** CAPTCHA e login são sempre feitos pela pessoa.
- ⚖️ **Julgamento:** o alt faz sentido? O texto é claro?
- ❓ **Dúvida:** o código parece certo, mas o comportamento visual não.
