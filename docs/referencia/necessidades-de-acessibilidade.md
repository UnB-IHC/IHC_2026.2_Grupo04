<aside markdown="1">

**Em uma frase:** acessibilidade não é só para pessoas com deficiência permanente — ela atende qualquer pessoa com uma limitação, seja ela **permanente, temporária ou situacional**.

</aside>

## 🧍 Os três tipos

<aside markdown="1">
♾️

**Permanente**

Cegueira, surdez, limitação motora, deficiência intelectual.

</aside>

<aside markdown="1">
⏳

**Temporária**

Braço quebrado, pós-operatório ocular, crise de enxaqueca.

</aside>

<aside markdown="1">
☀️

**Situacional**

Celular sob sol forte, local barulhento sem fone, bebê no colo.

</aside>

## 🎯 Por que importa

- O mesmo recurso ajuda os três grupos: legendas servem para quem é surdo, para quem está com o braço do fone quebrado e para quem está num ônibus barulhento.
- Projetar para o caso extremo melhora a experiência de todos (o chamado *efeito rampa*).
- Muitas dessas pessoas dependem de [Tecnologia Assistiva](tecnologia-assistiva.md).
