# Checklist para avaliar um site

Use este checklist para inspecionar a acessibilidade de qualquer site com base na ABNT NBR 17225 e na WCAG 2.2. Cada critério tem uma ficha com o que verificar; abra o nome do critério para ler as orientações.

## Como usar

1. Informe o site ou a página avaliada.
2. Para cada critério, siga a coluna **Como testar**, escolha o resultado e anote a evidência (página, elemento, captura).
3. Exporte as respostas em CSV ao terminar.

As respostas ficam salvas apenas neste navegador e não são enviadas a nenhum servidor. Prefere trabalhar numa planilha? [Baixe o modelo em CSV](../referencia/dados/checklist-modelo.csv).
