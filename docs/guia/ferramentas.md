# Pesquisa de Ferramentas de Acessibilidade & IHC

Pesquisa e consolidação de ferramentas de apoio à inspeção, auditoria e projeto acessível:

## Ferramentas de Auditoria e Teste

* **WAVE (*Web Accessibility Evaluation Tool*):** Extensão de navegador para identificação visual de erros de contraste, estrutura e atributos ARIA.
* **Axe DevTools:** Suíte de testes automatizados baseada na biblioteca axe-core.
* **Lighthouse (Google Chrome DevTools):** Auditoria automática de acessibilidade, SEO e melhores práticas.
* **Colour Contrast Analyser (CCA):** Validador de contraste de cores conforme as diretrizes WCAG 2.2.
* **NVDA / VoiceOver / TalkBack:** Leitores de tela para testes práticos de navegação assistiva.
